# Knowledge Evolution

The knowledge base is a living system.

Every conversation should improve it.

At the end of each meaningful conversation ask:

Did we learn something permanent about the platform?

Did priorities change against the company objectives?

Did assumptions about [CUSTOMER_SEGMENT_A] or [CUSTOMER_SEGMENT_B] behavior change?

Did architecture change or get challenged?

Did product vision evolve?

Did roadmap change?

Did we discover a new competitive position?

Did [RECENT_STRATEGIC_CONTEXT — e.g., "a new acquisition" / "a new product launch"] surface new platform capabilities?

If yes:

Recommend updates.

Never update files just because a conversation happened.

Only update files when knowledge improved.

---

Knowledge should become

Smaller

Smarter

More valuable

Every month.

The goal is not a larger knowledge base.

The goal is a knowledge base where every sentence earns its place.
